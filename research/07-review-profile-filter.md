# 리뷰/프로필/필터 설계 초안 (2026-11-11)

## 리뷰 (사용자 제안: 업체와 사람 상호 별점)
- 리뷰는 근무 기록(채용 확정 -> 쌍방 출근 확인)에 붙임
- 구인자 평가: 일당 제때 지급, 공고 조건 일치, 현장 안전, 분위기
- 구직자 평가: 출근 성실(노쇼), 숙련도, 매너
- 동시 공개, 자유 서술 제한, 신고/이의제기/임시 비공개, 낮은 별점으로 차단하지 않고 지표로 표시

## 필터 원칙 (법 확인 결과)
- 연령: 합리적 이유 없는 차별 금지, 직무상 불가피한 경우만 예외(고용상 연령차별금지법 제4조의4, 제4조의5), 구인자 벌금 500만 원 이하 가능
- 성별: 남녀고용평등법 제7조, 특정 성 우대 표현 위법, 직무상 불가피한 경우만 예외, 직무 무관 키/체중 요구 금지
- 군필 요구는 성별 우대 소지(내 해석, 판례 미확인)
- 위 법은 구인자 규제, 앱의 책임 범위는 미확인 -> 1350/법률 확인
- 첫 버전: 나이/성별/군필 필터는 넣지 않고 직무 관련 사실 항목(자격, 장비, 교육 이수, 경력, 가능 조건)으로 필터

## 프로필 (사용자 제안: 입문 장벽 낮게, 수정하며 채워나감)
- 가입: 전화번호 인증 + 직종 1개 + 지역, 바로 공고 열람
- 지원 시 필요한 항목만 그 자리에서 입력하고 자동 저장
- 항목: 직종/경력, 보유 자격, 교육 이수(건설이수증 취득 년월), 보유 장비, 가능 조건(숙식, 야간, 장기, 출발 가능일)
- 완성도 %, 증빙 업로드 시 확인됨 뱃지
- 공개 범위는 항목별 구직자가 선택, 생년월일/건강/키체중은 필수 아님
- 증빙 사진은 개인정보 가림 안내 + 최소 저장
- 구인자 프로필: 사업자 정보, 팀 규모, 진행 현장, 급여 지급일 정책, 보유 장비

## 단계
1. 공고, 프로필, 원터치 지원, 사업자 확인 뱃지
1.5. 근무 확인 + 쌍방 리뷰
2. 커뮤니티, 공사업자, 인테리어 급구
3. 광고, 결제

## 1350 문의 목록
- 직업정보제공 신고만으로 되는지, 무료직업소개 신고 필요 여부
- 개인 반장(사업자 없음) 공고 가능 여부
- 앱에 연령/성별 조건 입력 칸이나 필터를 두는 것의 책임 범위
