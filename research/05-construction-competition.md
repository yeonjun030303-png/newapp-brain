# 건설 인력 경쟁/법령 확인 (2026-11-10)

## 경쟁 (이전 "약한 편" 판단 철회)
- 가다: 건설 일용근로자 40만 명 이상 구직 중이라 소개(회사 주장), 건설사는 상담/계약 후 현장 개설, 반장 팀정보 등록 기능
- 일다오: 구인구직 + 무료 공수계산기 + 출근자 증빙서류/명단 다운로드 기능 추가
- 일당: 확정 근로자당 일당 2% 포인트 적립, 평점 3.6(7개)
- 기타: 일가자인력, 모든인력, 노무비닷컴(전자 대금지급), 어디GO, 콘업, 일용이

## 법령 (고용노동부 고시 국내유료직업소개요금 등)
- 구인자 소개요금: 임금의 30% 이하, 건설일용 10% 이하
- 구직자 요금: 사전 서면계약 필수, 건설일용 10% 관행은 대리수령 동의서 있을 때만
- 유료직업소개소는 시군구 등록 필요, 무등록 시 징역 5년 이하/벌금 5천만 원 이하
- 소개소는 구직자 몫을 사업주에게 선급금으로 미리 받을 수 없음
- 등록 조건(사무실 10제곱미터, 예치금 1000만 원 등)은 블로그 기준, 확인 필요

## 해야 할 일
- 경쟁 앱 5개 직접 사용 + 스크린샷
- 현장 사람 3~5명 인터뷰 (질문 7개)
- 1350 문의: 앱 소개료 수취 시 등록 필요 여부
- 착수 기준: 인터뷰 5명 중 3명 이상이 분쟁 경험 + 기존 앱 불만 + 사용 의향
