# 밴드/카톡 공고 분석 + 첫 버전 초안 (2026-11-10)

## 캡처에서 읽힌 것 (사용자 제공 스크린샷 2장: 밴드 1, 카톡 오픈채팅 1)
- 공고 항목이 고정적: 현장/지역, 직종, 단가(주간 1공수, 연장 1.5공수, 야간/철야 2공수), 숙식 단가, 근무시간/휴일, 급여 지급일, 조건(나이, 건설이수증, 4대보험), 시작일, 지원 방법
- 지원은 문자 양식 복붙(성명/생년월일/연락처/거주지/경력/건강/키체중/이수증/교육참석)
- 같은 공고가 카톡과 밴드에 동시 게시
- 카톡이 가독성 좋고 밴드는 나이대 높음, 채팅방 300개 이상, 소개소 포함 (사용자 의견), 오픈채팅방 인원 1,684명

## 방향
- 소개 위주로 시작, 광고료/대금 지급은 나중
- 키워드 검색 + 카테고리 필터(알바천국 방식)
- 공사업자(하청/입찰), 인테리어 급구는 2단계

## 법적 경계 (확인 필요 항목 포함)
- 구인구직 정보 제공 = 직업정보제공사업
- 구인자 사업자등록 서류 확인 의무 (2023.3 시행령 개정), 미제출 시 게재 금지 -> 개인 반장 공고 방식이 설계 핵심
- 지원자-구인자 연결(알선)은 직업소개에 해당할 수 있음(해석, 확인 필요), 무료는 지자체 신고, 유료는 등록(예치금 1천만 원, 사무실 10제곱미터)
- 거짓 구인광고 금지: 업체명, 근로조건 필수 표시
- 생년월일/건강/키체중은 개인정보 부담, 필수 항목만 수집

## 첫 버전 초안
- 구직자: 필터/키워드 검색, 표준 공고 상세, 프로필 1회 입력, 원터치 지원, 지원 내역
- 구인자: 표준 공고 작성, 카톡/밴드용 공유 텍스트+링크, 지원자 목록, 사업자 확인 뱃지
- 나중: 결제, 광고, 공사업자 입찰, 선지급

## 확인할 것
- 1350: 직업정보제공 신고만으로 되는지, 무료직업소개 신고 필요 여부, 개인 반장 공고 가능 여부, 공고에 연령 제한 항목을 둬도 되는지
